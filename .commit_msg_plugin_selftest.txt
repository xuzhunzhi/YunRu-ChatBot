测试：钉住"插件不许绝对自引用" + 一条改名实测（新文件）

外部审查实测的两个坏例子已经在上一提交改掉了，但它们**没有断言守着**——下一个插件
照抄一句 `from qq_roleplay_bot.plugins.<自己>.<模块> import …`，改名又会静默不装。
所以补一个文件，三条：

1. `test_no_plugin_has_an_absolute_self_import`
   扫 `plugins/*/` 下每个插件的 `.py`，用 **AST** 读 import 语句的**模块路径**
   （不是 grep 字符串，也不看 `import` 后面的名字），判据
   `(?:^|\.)plugins\.<自己>(?:\.|$)` 命中即红。两种写法都抓：

   * `from qq_roleplay_bot.plugins.vision.vision import …`（绝对）；
   * `from ...plugins.mail.mail_client import …`（**混在相对 import 里**——前导点
     看着像好写法，可 `...` 从 `…plugins.mail` 升三级正好落回 `…plugins`，
     后面的 `plugins.mail` 一样把文件夹名写死了）。

   `find_spec("qq_roleplay_bot.plugins.vision.vision")` 那类**不是 import**，不判红
   （`plugins/__init__.py` 与 `prompt_library` 靠它按名字问"在不在"）。

2. `test_no_plugin_imports_another_plugin`
   "插件 import 别的插件"那条禁令（`AGENTS.md` §2.3：依赖用 `REQUIRES` 表达）。
   **报告项**：审查要求"有就报，别自己修"。实测**命中一条**：
   `plugins/webui/webui_panel.py:561` 的 `from ..join_approval.join_approval import
   JOIN_SUB_TYPE, parse_pending`——改动前就在、与本次无关，所以**没动那个插件**，
   只把这一条写进 `ALLOWED_CROSS_PLUGIN_IMPORTS`，并断言"实测清单 == 已知清单"
   （多一条红；这一条将来被撤掉也红，提醒把这行删掉）。

3. `test_a_renamed_plugin_still_loads_and_registers`（端到端，改名的实测）
   把 `plugins/` 复制到临时目录、`vision/`→`zz_vision`、`mail/`→`zz_mail`，
   在**新进程**里把 `plugins.__path__` 换成副本树，跑真实的 `discover()`，
   要求两个新名字都在 `loaded` 里、且没有 `plugin_import_missing_module` /
   `plugin_register_failed`。副本用 `finally` 删干净。

   **为什么必须新进程**：本进程早就 import 过真插件，`sys.modules` 里已经有
   `qq_roleplay_bot.plugins.vision.vision`，改名前那条绝对 import 照样找得到——
   同进程测是**假绿**（实测对照：真树 `loaded=('mail','vision')` 0 条坏日志；
   副本里改回绝对写法 `loaded=()` + `plugin_import_missing_module name=zz_vision` +
   `plugin_register_failed name=zz_mail`）。

   两个踩过的坑写在测试里：子进程**不给 `run_single.py` 传额外的位置参数**
   （它把第一个之后的都当成要加载的文件，多给一个就 `'NoneType' object has no
   attribute 'loader'`），参数走环境变量；子进程的 `QQBOT_VERIFY_LOG_DIR` 指到临时目录，
   免得往真 `data/logs` 里混一条 `label=unit` 的凭证（那个凭证说的只是一次子进程内跑）。

   `outage_notice` 刻意不参与改名：它声明 `REQUIRES = ("mail",)`，副本里前置成了
   `zz_mail`，它必然被 `plugin_skipped_missing_dependency` 跳过（那是对的，与自引用无关）。

**这条断言在改之前会红**（实测，不是推断）：把 `vision/plugin.py` 与 `mail/wire.py`
各一处临时改回改前写法，`ran=3 failures=2 errors=0`，红的正是第 1 条
（`vision/plugin.py:56 from qq_roleplay_bot.plugins.vision.vision import …` 与
`mail/wire.py:40 from ...plugins.mail.daily_report import …`）与第 3 条
（`loaded=()`，改名的识图插件没装上）；改回来即 `failures=0`。
